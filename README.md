# ИВС-СЕТИ — варианты главного экрана

Прототипы первого экрана нового сайта [ivs-corp.ru](https://ivs-corp.ru). Next.js + React, стили — CSS-модули на токенах дизайн-системы ИВС (шрифт Inter, `red_main` #d83437).

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start   # продакшн-сборка
```

## Страницы

| Путь | Что это |
| --- | --- |
| `/` | Выбор варианта (карточки со скриншотами) |
| `/v1` | Вариант 1 — насыщенный красный фон (референс jet.su) |
| `/v2` | Вариант 2 — светлая тема (референс cortel.cloud/solutions) |
| `/v2-2` | Вариант 2.2 — вариант 2 с плашкой акцентного цвета |
| `/v3` | Вариант 3 — в работе |

`?clean` в адресе скрывает плавающий переключатель вариантов (для скриншотов).

## Где что лежит

- `components/ivs-content.ts` — наполнение: меню, слайды, направления, цифры (с ivs-corp.ru).
- `components/variants.ts` — список вариантов, скриншоты и комментарии для главной.
- `app/v1`, `app/v2` — код вариантов; `app/globals.css` — токены дизайн-системы.
- `public/hero` — 3D-иллюстрации (тестовые), `public/shots` — превью вариантов.
