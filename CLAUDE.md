# CLAUDE.md — контекст проекта «ИВС-СЕТИ: новый сайт»

Этот файл — память проекта для Claude. Прочитай его целиком перед любой работой. Общение с Антоном (владелец репозитория, дизайнер-разработчик) — по-русски.

## Заказ

- **Клиент:** ЗАО «ИВС-СЕТИ», Пермь (группа ИВС, с 1990 года). Текущий сайт — https://ivs-corp.ru (1С-Битрикс, устарел).
- **Контакты со стороны клиента:** Корягин Юрий (руководство), Денненбург Леонид (вопросы по ТЗ).
- **Задача сейчас:** показать руководству несколько вариантов **главного экрана (hero)**. Потом — дизайн и разработка всего сайта (срок — до конца года).
- **Пожелания клиента из ТЗ:** без ярких/глубоких цветов (отвлекают), без шрифтов с засечками, рукописных и художественных. Брендбука нет — только логотип. Форма обратной связи убирается (есть контакты). Разделы: О компании (история, лицензии, партнёры, отзывы), Услуги, Реализованные проекты, Новости и мероприятия (вливается https://iteventpermkrai.tilda.ws/), Контакты. Нужна админка для самостоятельного редактирования; не хотят зависеть от одного разработчика.
- **Стек согласован:** React + Next.js (+ своя админка/конструктор блоков позже; рассматривается и вариант на 1С-Битрикс как запасной).
- **Референсы клиента:** jet.su, cortel.cloud/solutions, unlim.group/partnery, softmall.ru/portfolio, center-ris.ru.

## Дизайн-система ИВС (обязательна)

- Артефакт: https://claude.ai/artifact/Pbef9A2amh5aQRNyJ4LEDK («ИВС-СЕТИ», тип Design System). Перед дизайн-работой читай его `project/README.md` и `project/tokens.css`.
- Шрифт — только **Inter**. Цвета: `red_main #d83437`, `red_pressed #b5282b`, `red_deep #88130c`, `red_light #d84346`, текст `#1f1e1e`, `text-muted #5c5a5a`, `surface-200 #f4f4f4`, `line #d4d2d2`. Шаг отступов 8px, радиусы 8/12/20/28/full, тени shadow-1/2/3. Токены продублированы в `app/globals.css`.
- **Логотип не перерисовывать и ничего к нему не добавлять** — только готовые файлы: `public/ivs-mark.svg` (на светлом), `ivs-mark-white.svg` (на красном/тёмном), `ivs-mark-gradient.svg` (буквы — прорези; на красном фоне подкладываем `ivs-mark-backing.svg`), `ivs-favicon.svg`. Слоган «Создаём будущее» рядом со знаком не ставим.
- Анимации: transform/opacity/цвет, ease-out (`cubic-bezier(0.23,1,0.32,1)`), hover только для мыши, `prefers-reduced-motion` уважаем, без `transition: all`.

## Правила по контенту

- **Наполнение не меняем — меняем дизайн.** Меню, услуги, слайды, направления, цифры берём с ivs-corp.ru (`components/ivs-content.ts`).
- Не выдумывать факты. Если текст сформулирован нами (описания слайдов, продающий заголовок варианта 2, тексты подсказок) — помечать это Антону как «на согласование».
- Иллюстрации в hero — тестовые (Антон генерирует 3D-иконки: PNG/WebP с прозрачностью, 1254×1254, лежат в `public/hero/`). Рядом с ними кружок «!» с подсказкой «Иллюстрация тестовая… В финальной версии я её заменю.»

## Проект

- Next.js 16 (App Router) + React 19 + TypeScript, CSS-модули. `npm run dev` → http://localhost:3000.
- `/` — выбор варианта (карточки со скриншотами из `public/shots/`, список в `components/variants.ts`, поля `short`, `image`, `comment`).
- `components/Switcher.tsx` — плавающий переключатель вариантов (`current` = href страницы). `?clean` в адресе скрывает его (для скриншотов). `devIndicators: false` в `next.config.mjs`.
- `components/direction-icons.tsx` — линейные иконки направлений (общие для вариантов).
- Репозиторий: https://github.com/koryaginstudio/ivs-site-hero (private), ветка `main`, push по SSH.

## Статус вариантов и принятые решения

### Вариант 1 — `/v1` (референс jet.su) — готов
- Насыщенный красный фон-градиент, который медленно «переливается» (3 пятна, анимация transform). Шапка — стеклянная полоса на всю ширину от верха, чуть светлее фона, в красном тоне (не белёсая).
- Светлый текст на красном — не чистый белый, а `#f3d9da` (чистый белый «режет глаза»).
- Меню при наведении: красная линия рисуется под пунктом слева направо (`#ff3347`, 3px, со свечением); то же у телефона и ссылки «Все услуги ›». Лупа — в круге с обводкой, телефон — жирный номер без обводки и без подписи «Пермь».
- «Заказать звонок» — красный «полированный хром» (из ДС AUTODISP проекта PASS, перекрашенный) — плоский, без 3D-кантов, яркий, со светлым контуром и свечением; блик пробегает при наведении.
- Слайдер из 3 слайдов ИВС: заголовок (600, 64px — «больше, а не жирнее»), под ним одна строка описания (без тегов). Переключение — точки (активная = «пилюля» с прогрессом), без цифр 01/02/03. Иконка справа приезжает сбоку, текст — сверху; лёгкий параллакс за мышью + увеличение при наведении.
- Ниже hero — 6 одинаковых карточек направлений 3×2 на белом; при наведении раскрываются вниз поверх соседних с подуслугами (место под раскрытие резервируется, страница не скачет).

### Вариант 2 — `/v2` (референсы cortel.cloud/solutions и кнопки с cortel.cloud/importozameshhenie-vmware) — готов
- Светлая тема: белая шапка, hero — светло-серая скруглённая плашка. Один продающий экран без слайдера: заголовок «Полный комплекс ИТ-услуг **для бизнеса и госсектора**» (акцент красным), описание, кнопки 60px/радиус 16 с квадратом-иконкой слева (как у Cortel, линия снизу при наведении), 3 карточки с цифрами (1400+, 200+, 36 лет) — при наведении заливаются красным, текст светлый.
- Справа 3D-иллюстрация `public/hero/v2-hub.webp`.
- Шапка: при наведении — плавающая серая «пилюля», перетекающая между пунктами (не подчёркивание). Мега-меню «Услуги» — две панели: слева 8 направлений с красными иконками, справа подуслуги выбранного в 2 колонки с разделителями (без горизонтальной прокрутки).
- Карточки направлений: белые с тонкой рамкой, **красные линейные иконки на белом, без подложек**. Анимации — очень мягкие (600ms, `cubic-bezier(0.22,1,0.36,1)`), с заметным приближением (scale) при наведении.

### Вариант 2.2 — `/v2-2` — готов
- Тот же вариант 2, но hero-плашка — радиальный градиент акцентного цвета (белый блик сверху → красный → бордовый), как hero у Cortel/VMware. Компонент `Hero` с пропом `accent`.

### Вариант 3 — `/v3` (референс unlim.group) — в работе, правки Антона по ходу
- Первая версия была отклонена: собрана без ДС (чужие цвета, хром из AUTODISP), шапка скопирована из варианта 1, анимации ломались. Урок: **перед дизайн-работой всегда читать ДС-артефакт** (`project/README.md`, `tokens.json`, `components/*/README.md`, `components/bundle.css`).
- Композиция как у референса: текст и плашки — одной группой слева, по вертикальному центру; правая половина — под текстуру. Фон `gradient-ink`, красный свет (радиальные градиенты из точек `gradient-brand`) — в правом нижнем углу и вверх по правому краю. Слева — неподвижное затемнение (на телефоне — сверху вниз).
- **Без надзаголовка** (Антон: двойные заголовки не делаем). Заголовок стиля hero ДС (800, −0.03em), до 64px, ровно в две строки, акцент `red_main`.
- **Кнопки — как в варианте 2**: 60px, скругление 16, квадрат-иконка 26px слева, при наведении подъём, иконка «выпрыгивает», снизу тонкая линия. «Заказать обратный звонок» — `red_main` (иконка телефона), «Все услуги» — тёмное стекло (стрелка ↗). Круглые «пилюли» Антону не нравятся.
- Шапка — стеклянная плашка (`material-glass`, `glass-edge`, `shadow-glass`), скругление 20; **знак красный** `ivs-mark.svg`; кнопка шапки 44px, скругление 12.
- Три плашки `.ivs-glass` — компактные (ряд до 880px под текстом, цифра 44px, подпись 14px под две строки), ссылки в разделы; hover — подъём 6px, светлее стекло, блик.
- Текстура — стеклянные ленты Антона `public/hero/v3-texture.webp` (прозрачный фон; верх и низ растушёваны прямо в файле), прижата вправо, поднята (bottom 8%, высота 92%). Наложение **`mix-blend-mode: overlay`** — ленты окрашиваются в красный, серого нет. Режим стоит на внешнем слое `.layerTexture`: внутренние слои изолированы, на них смешивание не работает. Рядом кружок «!» — «текстура тестовая».
- Производительность (Safari): на движущихся слоях — никаких `filter: blur()`, SVG-фильтров и масок; всё движение — `transform`. Из-за тяжёлого фона у Антона в Safari вставали все анимации, хотя в Chrome работали.
- Анимации: свет «переливается», лента плывёт, параллакс фона за мышью (`Hero.tsx`), появление 700ms с каскадом 80ms (паттерн `.ivs-reveal`: класс `ivs-motion` на `<html>` + `data-visible`), «пилюля» в меню. Недостающие токены ДС — в `app/globals.css`.

## Как работать

- Скриншоты и проверка: встроенный браузер или безголовый Chrome (`--headless=new --window-size=1440,900 --screenshot=… "http://localhost:3000/vN?clean"`). Превью для главной — 1440×900 @1.5, JPEG в `public/shots/`.
- Проверять ширины 375 / 720 / 960 / 1440 / 1920: без горизонтальной прокрутки, меню на 960 не должно схлопываться.
- Использовать скиллы ui-ux-pro-max и emil-design-eng для дизайна и анимаций.
- Коммиты — по-русски, с осмысленным описанием.
